# Sandra AI - Desktop Wrapper

**Sandra** is a modern graphical user interface (GUI) developed in Python for interacting with Google’s artificial intelligence models (Gemini). The project uses `customtkinter` to provide a fluid user experience with a native dark mode aesthetic.

## ✨ Features

- **Modern Interface:** Built with CustomTkinter for a sleek, responsive look.
- **Gemini API Integration:** Leverages Google’s latest model for fast, intelligent responses.
- **Local History:** Conversations are automatically saved in the `chats/` folder, ensuring persistence across sessions.
- **Multiple Chats:** Initial support for creating new conversation sessions.
- **Code Visualization:** Optimized formatting for reading messages and code generated by the AI.

## 🛠️ Technologies Used

- [Python](https://www.python.org/)
- [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter) (Graphical User Interface)
- [Google GenAI SDK](https://github.com/google/generative-ai-python) (Gemini Integration)
- [Python-dotenv](https://github.com/theskumar/python-dotenv) (Environment Variable Management)

## 🚀 Prerequisites

Before you begin, you will need:

1.  **Python 3.9+** installed.
2.  A **Google Gemini API Key**. You can generate one for free at [Google AI Studio](https://aistudio.google.com/). ## 🔧 Installation

1.  **Clone the repository:**
```bash
git clone https://github.com/your-username/sandra.git
cd sandra
```

2.  **Create and activate a virtual environment (optional, but recommended):**
```bash
python -m venv venv
# On Windows:
venv\Scripts\activate
# On Linux/macOS:
source venv/bin/activate
```

3.  **Install the dependencies:**
```bash
pip install customtkinter google-genai python-dotenv
```

4.  **Configure your API Key:**
Create a `.env` file in the project root and add your key:
```env
GEMINI_API_KEY=YOUR_KEY_HERE
```

## 💻 How to Use

To launch the application, run the main file:

```bash
python sandra_1.0.py
```

- Type your message in the text box at the bottom.
- Click **"San."** or press Enter (if implemented) to send.
- Use the **"New Chat"** button in the side menu to start a fresh conversation.

## 📁 Project Structure

- `sandra_1.0.py`: Main file containing the graphical user interface (GUI) logic.
- `ia_gemini.py`: Module for communicating with the Google API and managing conversation history.
- `chats/`: Directory where conversation history files (`.txt`) are stored.
- `.env`: File for the secure storage of your API key (should not be pushed to Git).
